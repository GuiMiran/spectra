# Authorship and provenance

SPECTRA identifies **Guido Miranda Mercado** (`@GuiMiran`) as its original
creator and maintainer. The GUIDO SDD ecosystem and its five-component
coordination model are documented here under Guido's direction. This statement
records attribution for the project's conception and maintained design; it
does not claim that no similar approach exists elsewhere.

The product name is explained as **SPEC**ifications + **TRA**ceability. This
descriptive mnemonic identifies SPECTRA's specification and traceability
focus; it does not claim ownership of those general practices. The historical
letter-by-letter project motto remains documented in the README and manifesto.

Contributions by other people remain attributable to their respective authors.
Repository commits, pull requests, review records, architecture decisions and
release notes provide the history of particular implementations and changes.
Use those records when attributing a specific file, feature or contribution;
do not infer that every line of code has a single author from this page.

authorship note does not amend the license, transfer rights, assert ownership
