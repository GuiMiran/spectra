Browse catalogue → View on GitHub Fill template → LLM generates 13 spec files → Agent builds autonomously "The specification framework designed to be consumed by AI, not humans." github.com/GuiMiran/spectra HOW IT WORKS Three steps to an autonomous agent SPECTRA converts business knowledge into structured specs that an agentic AI can consume directly — without guessing your rules. STEP 01 Fill the template Pick your business from the catalogue or fill SPECTRA-PROMPT.md with your domain knowledge — regulations, rules, flows, entities. STEP 02 LLM generates specs Send the prompt to Claude, GPT-4o or Gemini. It generates all 13 spec files — glossary, business rules, invariants, workflows, acceptance criteria. STEP 03 Agent builds Drop the /specs folder in your repo. The builder agent (Claude Code, Copilot, Cursor) reads the specs and builds the system autonomously. RESULT No business questions The agent knows every rule, invariant and workflow before writing a single line. It builds correctly the first time.
